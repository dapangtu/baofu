# A股尾盘选股工具

每天下午 14:50，从全市场 5000+ 只 A 股中，通过多因子模型自动选出次日最可能上涨的股票：**沪深主板 5 只 + 创业板 5 只**。支持 Web 仪表盘实时查看、历史选股查询与涨跌追踪。

## 功能特性

- **全市场实时行情**：通过通达信 TCP 协议获取 5000+ 只 A 股的实时 OHLCV 数据
- **分板块选股**：只选沪深主板（600/601/603/605 + 000/001/002/003）和创业板（300/301），排除科创板/北交所/B股；主板选 5 只、创业板选 5 只
- **多因子打分模型**：技术面 (50%) + 资金面 (25%) + 概念热度 (25%)，综合评分
- **技术指标覆盖**：MA 均线、MACD、KDJ、BOLL 布林带、RSI、量比
- **热点概念识别**：自动获取当日最热概念板块，行业关键词匹配评分
- **Web 仪表盘**：三栏布局，实时展示大盘概况、成交量排名、个股推荐和概念热度
- **MySQL 存档**：每日选股结果自动存入 MySQL，支持按日期/板块/代码搜索
- **涨跌追踪**：查询历史选股时自动计算每只股票从选出日至今的涨跌幅
- **结果存档**：选股结果同时保存 CSV，方便回测追踪

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置 MySQL

编辑 `config.py` 中的数据库配置（默认 `127.0.0.1:3306`，用户 `root`，密码 `666666`）。首次运行时自动创建 `baofu` 数据库和 `stock_picks` 表。

### 3. 启动 Web 仪表盘

```bash
python main.py --web
```

打开浏览器访问 `http://localhost:5000`，即可看到：

- 左侧：历史选股查询（按日期/板块/代码搜索，含选出日至今涨跌）+ 大盘概况
- 右侧：多因子模型选出的主板 Top 5 + 创业板 Top 5 推荐股票，含完整技术指标明细

### 4. 其他运行方式

```bash
# 完整模式 — 在终端中运行一次选股
python main.py --once

# 快速测试模式 — 减少 K 线天数，加快速度
python main.py --quick

# 指定端口
python main.py --web --port 8080
```

## 选股模型说明

### 板块范围

仅从沪深主板（600/601/603/605、000/001/002/003）和创业板（300/301）中选股，排除科创板、北交所、B股。**每日输出主板 5 只 + 创业板 5 只**。

### 硬过滤条件（不满足直接排除）

| 条件 | 参数 | 说明 |
|------|------|------|
| ST/退市 | 自动排除 | 名称含 ST、*ST、退市字样 |
| 停牌 | 自动排除 | 成交量为 0 或价格为 0 |
| 涨跌幅 | 1% ~ 9% | 太弱没动能，涨停附近追高风险大 |
| 换手率 | 2% ~ 15% | 太低没资金关注，太高出货嫌疑 |
| 流通市值 | 20亿 ~ 1000亿 | 排除庄股和大象股 |
| 量比 | ≥ 1.2 | 要求当日放量 |
| 大单净量 | ≥ 500万 | 大单净流入不足直接剔除（无数据时放行） |

### 资金面评分（25%）

资金面由两个子因子组成：**主力净流入 (60%)** + **大单净量 (40%)**。大单净流入体现大资金的真实买入意愿，大单净流出会显著拉低资金面得分。

### 多因子打分权重

| 维度 | 权重 | 子因子 |
|------|------|--------|
| **技术面** | 50% | 均线多头排列 (25%) + MACD (20%) + KDJ (20%) + 量比 (15%) + 布林带 (10%) + RSI (10%) |
| **资金面** | 25% | 主力净流入 (60%) + 大单净量 (40%) |
| **概念热度** | 25% | 所属行业是否匹配当日热点概念板块 |

最终得分 = 技术面×50% + 资金面×25% + 概念×25%，满分 100 分。其中大单净量低于 500万 的候选会被剔除。

## API 接口

Web 仪表盘通过以下 RESTful 接口获取数据：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/state` | GET | 后端状态轮询（是否在跑、更新时间等） |
| `/api/market` | GET | 大盘概况（指数、涨跌分布、成交量 Top 10） |
| `/api/recommend` | GET | 选股推荐结果（主板 Top5 + 创业板 Top5） |
| `/api/refresh` | POST | 强制触发新一轮选股 |
| `/api/picks` | GET | 历史选股查询，参数：`date`（日期）、`board`（板块）、`symbol`（代码），返回每只股票选出日至今涨跌幅 |

## 技术架构

- **行情数据**：[mootdx](https://github.com/foresight-org/mootdx)（通达信 TCP 协议，稳定不封 IP）
- **K线并发抓取**：多线程并发（默认 16 并发），每线程独立 TDX 连接，比串行快 3~5 倍
- **资金流熔断**：东方财富 API 连续失败自动熔断，不再逐只等待超时
- **概念板块**：东方财富 HTTP API（低频调用）
- **Web 框架**：Flask
- **前端**：内联 HTML/CSS/JS 单页应用（无额外依赖）
- **定时刷新**：前端每 3 秒轮询状态，数据更新后自动渲染

## 性能优化

单次全量选股（全市场 5000+ 只，过滤后约 2800 候选）耗时约 **3~5 分钟**：

| 阶段 | 优化前 | 优化后 |
|------|--------|--------|
| 行情获取 | ~1 分钟 | ~1 分钟 |
| K线抓取（2790 只） | ~9 分钟 | ~3 分钟（16 并发） |
| 评分（含资金流） | ~7 分钟 | ~1 秒（熔断 + 预取缓存） |
| **总计** | **~20 分钟** | **~4 分钟** |

> 说明：东方财富 API（资金流/概念）在部分网络环境下不可达，此时资金流评分为基础分、大单净量过滤放行（不误杀）。数据源恢复后资金流评分自动生效。

## 注意事项

1. **非投资建议**：本工具仅供学习和研究参考，不构成任何投资建议
2. **数据延迟**：通达信 TCP 行情有约 3-5 秒延迟，非 Level-2 数据
3. **网络依赖**：需要能连接通达信行情服务器，防火墙需放行相关端口
4. **深圳股票名称**：部分深市股票暂时用代码替代名称（mootdx 数据限制）
